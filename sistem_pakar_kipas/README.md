# Sistem Pakar Diagnosis Kerusakan Kipas Angin Portabel Genggam (Forward Chaining)

## Struktur
- `index.html`            : halaman utama (buka file ini)
- `css/style.css`         : tampilan
- `js/knowledge_base.js`  : fakta, kesimpulan antara, diagnosis, 19 aturan
- `js/inference.js`       : mesin inferensi Forward Chaining (`infer`, `sat`)
- `js/app.js`             : konsultasi, validasi, hasil, penjelasan, tabel basis aturan
- `js/tests.js`           : 6 skenario pengujian dan tingkat kesesuaian

## Menjalankan
Klik dua kali `index.html` (Chrome, Edge, atau Firefox). Tidak perlu instal apa pun.
Di VS Code: pasang ekstensi Live Server, klik kanan `index.html`, pilih Open with Live Server.
